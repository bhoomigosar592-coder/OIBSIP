# 💻 Personal Portfolio Website – BG.

## 📌 About the Project

This is a personal portfolio website developed to showcase my skills, educational background, projects, and learning journey as a Third Year IT Engineering Student.

The portfolio is designed with a clean, modern, and responsive layout to present my technical skills, projects, and contact information in an organized way.

## ✨ Features

- **Home Section:** Introduction with my name and professional profile.
- **About Section:** Brief information about my background and interests.
- **Skills Section:** Showcases my technical skills, including HTML, CSS, C, Python, Java, C++, and ERP SAP.
- **Projects Section:** Displays selected academic and practical projects.
- **Contact Section:** Provides email and social media links.

## 🚀 Projects Included

1. **Glowify – Skincare Landing Page**
   - A modern skincare landing page built using HTML and CSS.

2. **Personal Portfolio Website**
   - A portfolio website showcasing my skills, projects, and journey.

3. **SAP ERP – Student Table & MM/PO**
   - Worked with ABAP programming to create a Student Table and manage structured student data.

4. **Deloitte – Data Analytics Job Simulation**
   - Completed a virtual job simulation through Forage.

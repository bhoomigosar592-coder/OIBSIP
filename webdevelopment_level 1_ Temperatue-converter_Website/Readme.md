# Temperature Converter Website

A responsive temperature conversion tool built with **HTML5, CSS3 and Vanilla JavaScript**. It converts values between Celsius, Fahrenheit and Kelvin and displays all three units together.

## Features

- Numeric temperature input with validation.
- Celsius, Fahrenheit and Kelvin input-unit selector.
- Converts and displays all three temperature units at once.
- Friendly error message for empty or invalid input.
- Rejects values below absolute zero.
- Responsive, centered user interface.
- Results rounded to two decimal places.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Conversion Formulas

- Celsius to Fahrenheit: `(°C × 9/5) + 32`
- Fahrenheit to Celsius: `(°F − 32) × 5/9`
- Celsius to Kelvin: `°C + 273.15`
- Kelvin to Celsius: `K − 273.15`

# 🌿 Glowify – Skincare Landing Page

## 📌 About the Project

Glowify is a modern and visually appealing skincare landing page developed using HTML5 and CSS3. It promotes a skincare brand through an attractive layout, simple navigation, and engaging content.

## ✨ Features

- **Home Section:** Attractive hero section introducing the Glowify brand.
- **Features Section:** Highlights Nature Inspired, Deep Hydration, and Everyday Radiance.
- **About Section:** Introduces the brand and its vision.
- **Testimonials Section:** Displays sample customer feedback.
- **Call-to-Action Section:** Encourages visitors to explore and connect.
- **Contact Section:** Includes social media and email links.

## 🛠️ Technologies Used

- HTML5
- CSS3
